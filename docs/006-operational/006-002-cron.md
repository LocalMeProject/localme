# Cron Jobs

LocalMe provides a robust scheduled task system backed by the database.

## Execution
Cron jobs are invoked via `/api/cron/run`. A shared `PLATFORM_CRON_TOKEN` (`x-cron-token` header) allows the runner to execute every due task across all projects. Without it, cron tasks only execute when a project explicitly invokes its own tasks.

## Built-In Tasks
1. **SSL Certificate Renewal:** Sweeps for expiring Let's Encrypt certificates every 6 hours (`cron.task.renew_ssl_certificates.enabled`).
2. **Webhook Retry:** Re-attempts failed outbox deliveries using an exponential backoff.
3. **Storage Audit:** Periodically audits the `storage_data/` directory against the database records to enforce limits.
4. **Heartbeat:** Regular system state check.

Individual project owners can also configure their own database-backed scheduled tasks with custom intervals (`schedule` or `every_minutes`).
