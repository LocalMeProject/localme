# Users

The platform serves five distinct audiences:

1. **Admins:** Have full control over the platform, including deleting accounts/projects, changing roles, and impersonating other admins.
2. **Operators:** Run the platform day-to-day. Can manage accounts, suspend/unlock projects, impersonate ordinary users, manage configuration, cron jobs, and the shared library.
3. **Developers (Project Owners):** Build frontend applications and host them on LocalMe. They manage their projects, configure webhooks/cron, and upload assets.
4. **Visitors (End-Users):** Users of the hosted frontend applications. They have project-scoped roles, captcha-gated logins, and interact with the project-scoped database and storage via visitor sessions.
5. **Autonomous AI Agents:** AI coding assistants that interact with the platform using the Model Context Protocol (MCP) to automate project setup and management.
