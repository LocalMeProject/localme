# KPIs and Analytics

LocalMe tracks usage rollups and analytics to provide operational insight for both the platform administrators and project owners.

## System KPIs Tracked
1. **Bandwidth:** Bytes served per project, including static file transfers and API responses. Monitored per tier quota.
2. **Storage Usage:** Disk footprint of uploaded static assets and database size on the single-volume storage.
3. **Database Operations:** Read/write operations volume for the JSON document API per project.
4. **Visit Analytics:** Visitor sessions, logins, and project site visit metrics (tracked and seeded for up to two months).
5. **Webhook Reliability:** Webhook delivery success rates, failures, and outbox retry attempts.
6. **SSL Renewals:** Number of successful and failed ACME HTTP-01 renewals.

These KPIs are displayed in the Admin Console and the User Dashboard for individual project owners. Usage metrics directly influence the dynamic multi-tier subscriptions and limits enforcement.
