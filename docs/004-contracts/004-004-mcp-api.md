# MCP API Contract

Endpoints and integrations for the Model Context Protocol (MCP 2024-11-05).

## Interfaces

- `POST /api/mcp` - JSON-RPC 2.0 endpoint for MCP communication over HTTP. Implements protocol initialization, capability negotiation, ping, and logging level selection.
- `stdio` bridge - Located at `bin/mcp-server.mjs`, provides standard input/output bridge for local agent environments.
- `/skills/localme/SKILL.md` - Plain-text agent skill served directly.

## Capabilities

The platform exposes 16 native tools for agents:
- Account and project information.
- Static file and asset management.
- Route rewrites and proxy mounts.
- JSON document database operations.
- Encrypted secret management.

Real-time state and parameterized documentation are available via MCP resources (e.g. `localme://system/overview`, `localme://system/routes`).
