# Database API Contract

JSON document database endpoints scoped to the caller's project.

## Endpoints

- `GET /api/db/:collection` - List documents in a collection.
- `POST /api/db/:collection` - Create a new document.
- `GET /api/db/:collection/:id` - Retrieve a document.
- `PUT /api/db/:collection/:id` - Update a document.
- `DELETE /api/db/:collection/:id` - Delete a document.

All routes enforce permissions based on the active API key or visitor session role.
