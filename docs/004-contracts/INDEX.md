# Contracts

API Contracts and endpoint definitions.

- `001-auth-api` — Authentication endpoints and visitor sessions
- `002-db-api` — JSON document database API
- `003-storage-api` — File storage API
- `004-mcp-api` — Model Context Protocol endpoints
- `005-import-export-api` — JSON/ZIP project workspace export/import
- `006-permissions` — API key grants and visitor roles
- `007-subscription-api` — Dynamic multi-tier subscriptions and quotas
- `008-project-config-api` — Proxies, routes, secrets, roles, webhooks
