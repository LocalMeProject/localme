منطق تجاری برنامه را در لبه شبکه بدون سرور اجرا کنید

بدون اتلاف وقت برای تنظیمات سرور لینوکس، کدهای محاسباتی و ادغام های سفارشی را با زمان شروع زیر ۱۰ میلی ثانیه در محیط سرورلس لوکال می اجرا نمایید.

قابلیت های توابع لبه لوکال می

✓

شروع سریع بدون تاخیر سرما (Instant Cold-Start)

محیط محاسباتی سبک لوکال می در چند میلی ثانیه فعال شده و درخواست های شما را بی درنگ پاسخ می دهد.

✓

ایزولاسیون کامل حافظه و زمان اجرا

سندباکس امن برای هر اجرا با کنترل سقف مصرف رم و زمان تایم اوت جهت تضمین سلامت پایدار پلتفرم.

✓

دسترسی مستقیم به داده های پروژه

توابع لبه دسترسی درون شبکه ای بسیار سریع به جداول پایگاه داده و ذخیره ساز S3 همان پروژه دارند.

نمونه فراخوانی تابع از کلاینت

فراخوانی توابع با ارسال پارامترها و دریافت نتایج JSON:

کد Dart در فلاتر:
// فراخوانی تابع محاسبه تخفیف و صدور فاکتور final response = await client.functions.invoke( 'process-checkout', body: { 'cart_id': 'cart_84920', 'coupon': 'NOROOZ1405' }, ); print('وضعیت محاسبه: ${response.data['status']}');
کد TypeScript در وب:
// فراخوانی از فرانت اند وب const { data, error } = await client.functions.invoke('generate-report', { body: { period: 'monthly' } });
