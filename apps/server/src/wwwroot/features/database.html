پایگاه داده رابطه ای ابری بدون نیاز به نوشتن API

لوکال می یک پایگاه داده چندمستاجره کاملا مدیریت شده بر بستر PostgreSQL 18 با ایزولاسیون کامل پروژه ها، فیلترهای پیشرفته و امنیت در سطح سطر (RLS) در اختیار اپلیکیشن شما قرار می دهد.

مزایای کلیدی پایگاه داده لوکال می

✓

تفکیک اسکیمای اختصاصی به ازای هر پروژه (Schema Isolation)

هر پروژه دیتابیس مستقل خود را داراست و هیچ کوئری کلاینتی امکان دسترسی به داده های سایر پروژه ها را ندارد.

✓

امنیت در سطح سطر داده ها (Row-Level Security)

با تعریف سیاست های RLS، هر کاربر تنها به رکوردهایی دسترسی پیدا می کند که شناسه او در ستون مالکیت ثبت شده باشد.

✓

تاخیر سراسری زیر ۳۰۰ میلی ثانیه و آپتایم ۱۰۰٪

اتصال مستقیم دیتاسنترهای تهران به IXP کشور تضمین می کند که کوئری های اپلیکیشن با حداکثر سرعت در تمامی اپراتورها پردازش شوند.

نمونه کوئری از کلاینت بدون نیاز به کنترلر سرور

با کتابخانه کلاینت لوکال می مستقیما جداول را فیلتر، صفحه بندی و مرتب سازی کنید:

کد Dart در فلاتر:
// دریافت لیست محصولات فعال مرتب شده بر اساس قیمت final products = await client .table('products') .select('id, title, price_irr, stock') .filter('is_active', 'eq', true) .filter('stock', 'gt', 0) .order('price_irr', ascending: true) .limit(20) .execute();
کد TypeScript در ری اکت و وب:
// ثبت سفارش جدید توسط کاربر وارد شده const { data, error } = await client .table('orders') .insert({ user_id: client.auth.currentUser.id, total_irr: 4500000, status: 'pending' });
