احراز هویت ایمن، سبک و توکن محور برای اپلیکیشن ها

بدون نیاز به پیاده سازی دیتابیس جداگانه برای کاربران یا هش کردن دستی پسوردها، کاربران خود را با توکن های امن استاندارد JWT در لوکال می مدیریت کنید.

امکانات کلیدی سرویس احراز هویت

✓

ثبت نام و ورود با نام کاربری و ایمیل

پشتیبانی از ورود امن، بازیابی اعتبار، هشینگ چندلایه کلمات عبور و جلوگیری از حملات Brute-Force.

✓

صدور توکن های استاندارد JWT با قابلیت ابطال

توکن های دسترسی با امضای دیجیتال و امکان مدیریت نشست ها در اپلیکیشن های موبایل و وب.

✓

اتصال خودکار به قوانین امنیتی دیتابیس (RLS Integration)

شناسه کاربر لاگین شده مستقیما در کوئری های دیتابیس تزریق می شود تا دسترسی فقط به رکوردهای مجاز محدود گردد.

نمونه کدهای ورود و ثبت نام در کلاینت

فراخوانی متدهای آماده احراز هویت با چند خط کد ساده:

کد Dart در فلاتر:
// ورود کاربر با ایمیل و رمز عبور final session = await client.auth.signInWithPassword( username: 'user@example.ir', password: 'StrongPassword123!', ); if (session.isAuthenticated) { print('کاربر با شناسه ${session.user.id} وارد شد'); }
کد TypeScript در وب و React Native:
// ثبت نام کاربر جدید const { user, token } = await client.auth.signUp({ username: 'frontend_dev', email: 'dev@company.ir', password: 'SuperSecretPassword' }); console.log('ثبت نام با موفقیت انجام شد:', user.id);
